# 仓库品牌名公开初筛（2026-07-31）

## 结论

用户已决定采用 **Pernavo**，用于本地优先、跨 agent 的 Skills、记忆与工具编排产品。它不含 `Loong`、`Long`、龙或旧品牌的连续性暗示；名称由 *persistent navigation* 抽象而来，表达「让每个 agent 持续获得可定位的本地智能」，而不是绑定某一种模型、CLI 或运行时。

| 顺序 | 名称 | 读音 / slug | 语义与定位 | 初筛风险 |
| --- | --- | --- | --- | --- |
| 1 | Pernavo | per-NAH-vo / `pernavo` | *persistent navigation* 的造词；本地知识、技能与工具能力可持续地被 agent 定位和调用 | 低：根级 npm registry 404、PyPI JSON 404、GitHub repository name search 0；仍未做商标或域名核验 |
| 2 | Meralto | meh-RAL-to / `meralto` | 温和、稳健的抽象品牌名 | 中：npm/PyPI 404；GitHub 名称匹配 1（`meralto/meralto.github.io`），公开网页还出现同名赛马/姓氏噪声 |
| 3 | Mnexis | M-NEK-sis / `mnexis` | 将 memory 与 nexus 的联想压缩成抽象词 | 中高：npm/PyPI 404；GitHub 名称匹配 1（`esrshn/MNEXIS_SNN_Project`），并有游戏名称与科研缩写噪声 |

已确定的品牌架构：品牌 **Pernavo**；仓库 `pernavo`；未来包名 `pernavo-skills`；标语 **“Local intelligence for every agent.”**

## 已核验的初筛信号

本轮仅做公开网页、公开 registry 与 GitHub 名称层的排重。`Pernavo` 在根级检查中，npm registry 查询为 404、PyPI JSON 查询为 404，GitHub repository name search 返回 0。`Meralto` 与 `Mnexis` 的 npm/PyPI 查询亦为 404，但均已有 GitHub 名称匹配，因此不是首选。

这些结果只说明在本轮检查范围内未见同名公开包或同名仓库占用；**不是**商标、公司名、社媒 handle、目标域名可用性或不侵权证明。正式采用前，应以拟注册地区与类别完成 CN/US/EU 商标检索，并逐一核验目标域名及主要社媒账号。
